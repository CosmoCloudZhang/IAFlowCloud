# IAFlowCloud

Research project exploring intrinsic alignments, nonlinear-alignment models,
three-dimensional power spectra, and machine-learning-based data compression.

## Project structure

- `Code/` — Jupyter notebooks and analysis code
- `Data/` — cosmological parameters and local datasets
- `Figure/` — generated figures
- `Reference/` — lecture slides and project documents

## Current notebooks

- `Code/CCL.ipynb` — introduction to PyCCL and cosmological power spectra
- `Code/NLA.ipynb` — flexible nonlinear-alignment model and training-data generation
