   panel's title while retaining the

## Architecture diagrams

`Report/scripts/build_section4_figures.py` generates the convolutional and
PCA-assisted autoencoder diagrams from the reported three-hidden-layer
configurations. The figures use projected arrays and vector strips to show
representation changes. Printed dimensions are exact; geometric proportions
are schematic. Only input and output array rows represent physical redshifts.
Hidden convolutional channels contain learned combinations of the inputs.
The PCA-assisted diagram distinguishes the fixed rank-30 projection from
the learned coefficient encoder and decoder.

The luminosity panel's middle heading uses "Evolution index" for xi,
matching Section 3. The numerical curves and their ordering are unchanged.
