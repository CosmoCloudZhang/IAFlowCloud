\section{Introduction}
\label{sec:introduction}

How can we study matter that we cannot see? One approach is to look at the
shapes of distant galaxies. As their light travels towards us, the gravity of
intervening matter slightly distorts their images. These distortions are too
small to identify reliably in a single galaxy, but patterns across many
galaxies reveal how matter is distributed. This method, called \emph{weak
gravitational lensing}, helps astronomers test how the Universe expands and
how its structures grow \citep{2001PhR...340..291B}.

There is a complication: galaxies can have related orientations even before
their light is bent. The gravitational environments in which galaxies form
and evolve can influence their shapes. These \emph{intrinsic alignments}
contribute to the same patterns that astronomers use to measure lensing.
Understanding them is therefore part of making a reliable measurement of
the Universe \citep{2025A&ARv..33....5C}.

An alignment model needs to allow for uncertainty in how this effect changes
with the size of the structures being studied and with cosmic time. Adding
adjustable parameters gives a model more freedom, but can also make its
parameters harder to constrain. Different parameter choices may produce
similar predictions. If so, it may be possible to
describe the model's predictions with fewer numbers while keeping a useful
level of accuracy. This approach is called \emph{dimensionality reduction}.

We investigate this idea using a family of synthetic alignment-response
surfaces. Each surface is a table describing how the model's alignment
strength changes with spatial scale and redshift, a measure of cosmic
expansion. Thirteen parameters control these variations. Each surface is
evaluated on a grid of $31\times101=3{,}131$ points. The original 13 parameters already
provide a way to reproduce those values. Our question is whether an even
shorter, approximate description can capture their main variations.

\begin{quote}
\emph{Can an autoencoder describe an intrinsic-alignment response surface
using two numbers and reconstruct it more accurately than a linear method
using the same number of values?}
\end{quote}

We compare two established methods. Principal component analysis (PCA)
describes each surface by combining a small set of shared patterns
\citep{2016RSPTA.37450202J}. An autoencoder is a neural network that learns to
pass a surface through a small intermediate representation and then rebuild
it \citep{2006Sci...313..504H}. We generate a controlled dataset, train the
methods on the same training samples, and compare their reconstructions on
the same validation samples. We examine difficult surfaces as well as
average performance.

Neural networks already have applications in cosmology, including the
prediction of power spectra \citep{2022MNRAS.511.1771S}. Our specific
contribution is to test a flexible alignment-response family, compare two
methods under the same conditions, and identify where a short description
loses accuracy. The preliminary comparison reported in
Section~\ref{sec:results} suggests that two learned numbers can improve on
two PCA coefficients, but still miss important variation. This makes the
limits of compression part of the result. Reconstructing these synthetic
surfaces does not yet establish that they can replace an alignment model in
an analysis of real galaxy observations.
