\section{Detailed model equations}
\label{app:detailed-equations}

This appendix collects the parameterization omitted from the main narrative.
The cosmological factor in Equation~\ref{eq:a-omega} is
\begin{equation}
  \mathcal A_\Omega(z)=C_1\frac{\Omega_{\rm m}}{D(z)},
\end{equation}
with $C_1=0.0134$ and $D(z)$ the linear growth factor.  The redshift
variables relative to the fixed pivot $z_*=0.5$ are
\begin{equation}
  r(z)=\frac{1+z}{1+z_*},
  \qquad
  r_q=\frac{1+z_q}{1+z_*}.
\end{equation}
The broad redshift trend and the luminosity factor are
\begin{equation}
  \begin{aligned}
    R_z(z) &= r(z)^\eta,\\
    R_L(z) &=
    \left[
      \frac{1+[r(z)/r_q]^s}{1+(1/r_q)^s}
    \right]^{\xi/s}.
  \end{aligned}
\end{equation}

The characteristic scale and shape quantities evolve as
\begin{equation}
  \begin{aligned}
    k_t(z) &= k_{t,*}\,r(z)^{\gamma_t}, &
    n(z) &= n_*\,r(z)^{\gamma_n},\\
    \alpha(z) &= \alpha\,r(z)^{\gamma_\alpha}, &
    m(z) &= m\,r(z)^{\gamma_m}.
  \end{aligned}
\end{equation}
With $x=k/k_t(z)$, the scale response is
\begin{equation}
  S(k,z)=1+q\,
  \frac{x^{n(z)}}{1+x^{n(z)}}
  \left(\frac{1+x^{m(z)}}{2}\right)^{\alpha(z)/m(z)}.
\end{equation}
Together these factors give the positive surface in
Equation~\ref{eq:shape_surface} of the main text.  The autoencoder
normalization, encoder map, and training loss are stated in
Section~\ref{sec:autoencoder}.

\section{PCA autoencoder structure}
\label{app:pca-ae}

PCA-AE tests whether a nonlinear map is still useful after a linear basis
has already removed most of the surface variation.

\subsection{Structure}

Each normalized log-surface is first projected onto a frozen rank-30 PCA
basis fit on the training set.  The thirty coefficients are standardized
with training-only means and scales, then passed through a symmetric
multilayer perceptron
\begin{equation}
  30\to 256\to 64\to 16\to L\to 16\to 64\to 256\to 30,
\end{equation}
with SiLU activations, no dropout, and no internal normalization.  The
decoder coefficients are mapped back through the inverse PCA transform to a
reconstructed surface.  The PCA matrices are not trained.  The same
bottleneck widths $L\in\{2,4,6,8,10\}$ are used as for Conv1D.

The training loss is a weighted coefficient mean squared error constructed
so that it equals the contribution of those thirty components to the
normalized-surface MSE.  Errors that live in the discarded PCA tail cannot
be reduced by the network; they form a reconstruction floor.  The Depth03
network at $L=6$ has 51,076 trainable parameters.

\subsection{Design motivation}

Three design choices are deliberate.  First, rank 30 is already an accurate
linear summary of this family: a nearby training PCA rank accounts for
essentially all of the log-surface variance.  Compressing thirty
coefficients is cheaper than learning filters on the $31\times101$ grid, and
the neural parameter count is smaller by more than an order of magnitude
than a three-layer Conv1D network.

Second, the remaining map $30\to L$ is still nonlinear.  If PCA-AE and
Conv1D reach similar validation errors at the same $L$, the convolutional
filters are not buying much beyond a short nonlinear code of a good linear
basis.  If Conv1D is better, especially in the tails, the extra capacity is
doing work that a rank-30 front end cannot.

Third, freezing the basis keeps the comparison honest.  The network cannot
rotate the PCA axes or recover discarded components.  Table~\ref{tab:validation-results}
should therefore be read as a test of nonlinear compression inside a linear
subspace, not as a second unconstrained autoencoder.  The reported Depth03
cells are run \texttt{20260822-192700}.

\section{Reproducibility checklist}
\label{app:reproducibility}

\begin{itemize}
  \item Code version: Git commit \texttt{2a56362} in the IAFlowCloud
        repository.
  \item Authoritative dataset: \texttt{Data/NLA/Samples/NLA.hdf5}, containing
        coordinates, the 13 shape parameters, factorized components, and the
        stored train/validation/test indices.
  \item Parameter order and sampling bounds:
        Table~\ref{tab:sampling-bounds} in Section~\ref{sec:model}.
  \item Coordinate grid and split sizes: 31 redshifts from $z=0$ to $z=3$,
        101 logarithmically spaced wavenumbers from
        $k=0.01$ to $10\,{\rm Mpc}^{-1}$, and an $80{,}000/10{,}000/10{,}000$
        split (Section~\ref{sec:model}).
  \item PCA artifacts: \texttt{Data/NLA/PCA/}, including
        \texttt{PCAValidationMetrics.json} and the rank-25 joblib transform.
        The physical-model and PCA notebooks use the CosmoConda environment
        (Python~3.12, NumPy~2.0, scikit-learn~1.7, PyCCL~3.2).
  \item Reported Conv1D cells: Depth03, seed 42, run
        \texttt{20260909-003908}, latent widths $2,4,6,8,10$.
        Parameter counts range from $2{,}041{,}857$ at $L=2$ to
        $2{,}042{,}121$ at $L=10$.  The shared training template is
        Table~\ref{tab:training-config-details}.
  \item Reported PCA-AE cells: Depth03, frozen rank-30 PCA, hidden widths
        $256$, $64$, and $16$, run \texttt{20260822-192700}, documented in
        Appendix~\ref{app:pca-ae} and
        \texttt{Config/NLA/PCA\_AE/Depth03.yaml}.
  \item Random seeds: dataset split seed stored in the HDF5 generation
        metadata; reported autoencoder seed 42 in the shared training
        template.  Deterministic kernels are not enforced.
  \item Final test evaluation: not run.  The complete test split is reserved
        until architecture and training choices are frozen.
\end{itemize}

\section{Implementation notes}

The physical model lives in the \texttt{ia\_models.nla} package.  The learning
workflow lives in \texttt{iaflow}.  Shared surface data are cached once as
$\log_{10}\mathcal A_\Theta$ with training-only mean and global RMS
normalization.  Evaluation, diagnostics, and latent export read a run's
resolved configuration rather than an edited YAML file, so a checkpoint cannot
silently change its architecture after training.
