\begin{abstract}
Weak gravitational lensing uses the apparent shapes of distant galaxies to
study matter that cannot be seen directly.  A practical difficulty is that
galaxies can already point in related directions before their light travels
toward us.  This intrinsic-alignment effect can imitate part of the lensing
signal and therefore has to be modelled if weak gravitational lensing is to be used as a
cosmological probe.

Flexible alignment models do not return a single number.  They return a
surface of amplitudes over wavenumber and redshift.  In this project the
surface has $31\times 101=3{,}131$ values.  Nearby points on the surface are
strongly related, so the grid almost certainly contains far fewer independent
pieces of information.  The scientific question is whether those 3,131 values
can be represented by a much shorter description, and whether a nonlinear
method improves on a linear one at the same length.

We first write a phenomenological nonlinear-alignment model in which the
signed amplitude factors as
$\mathcal A_{\rm IA}=-A_0\,\mathcal A_\Omega\,\mathcal A_\Theta$.  Only the
positive shape surface $\mathcal A_\Theta$ is compressed.  Thirteen shape
parameters are sampled from documented training ranges, not from survey
posteriors.  After random-sample and full-corner checks, we generate 100,000
valid surfaces and store a leak-free partition of 80,000 training, 10,000
validation, and 10,000 test surfaces.

A principal-component baseline is then fit on the training set alone.  Two
PCA components recover $96.23\%$ of the held-out validation variance.  Ten
components recover $99.94\%$.  Against that baseline we train a
one-dimensional convolutional autoencoder at latent widths
$L\in\{2,4,6,8,10\}$.  On the same validation split, the latest three-layer
run with $L=2$ recovers $98.65\%$ of the total variance, with a
$\log_{10}\mathcal A_\Theta$ RMSE of $0.0319$ and a mean physical relative
error of $5.30\%$.  At $L=6$ the same architecture recovers $99.92\%$, and
at $L=10$ it recovers $99.997\%$.  At equal latent dimension the
autoencoder outperforms PCA.

A nonlinear representation is therefore useful for this family.  It does
not follow that a chosen $L$ is already sufficient for cosmological
analysis.  All autoencoder numbers are validation results from a single
seed.  The test split has been left unread.  The next experiment is a
multi-seed repeat of the most promising cells, then one evaluation of the
frozen test set.
\end{abstract}
