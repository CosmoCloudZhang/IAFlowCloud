\begin{abstract}
Weak gravitational lensing uses the shapes of distant galaxies to study matter
that we cannot see directly.  A difficulty is that galaxies can already point
in related directions before their light travels toward us.  This effect,
called intrinsic alignment, can imitate part of the lensing signal.  In this
project, we build a flexible mathematical model of intrinsic alignment and
generate many smooth amplitude surfaces over scale and redshift.  Each surface
contains 3,131 values, which is inconvenient for later statistical analysis.
We therefore ask whether the main information can be represented by only a few
numbers.  We first establish a linear baseline with principal component
analysis (PCA), and then train a one-dimensional convolutional autoencoder with
a two-number bottleneck.  On the held-out validation set, the current
two-number autoencoder recovers \placeholder{final value after the model is
frozen} of the total variance, compared with \placeholder{matched PCA value}
for two-component PCA.  We discuss what this result does and does not show,
including reconstruction errors in difficult cases and the need for a final
test-set evaluation.
